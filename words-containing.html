FAQ

What does “words containing” mean?

A word that has those letters in a row, anywhere inside it. FINGER contains ING; OTHER contains TH. It is not the same as “must include these tiles in any order” on the unscrambler — this hub matches the cluster as a substring.

How many English words contain Q?

2,473 ENABLE words contain Q. Most of them also have a U. The dump list is on Q without U.

How is this different from words starting or ending with?

Starting with is a prefix. Ending with is a suffix. Containing finds the letters in the middle too — useful for crossword fragments and Wordle yellows that sit together.

Can I search without a rack?

Yes. Leave Letters empty and type a letter or cluster (TH, QU, ING) in Must include. Pick a length if the list is huge.
