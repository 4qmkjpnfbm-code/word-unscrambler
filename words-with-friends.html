WWF is not Scrabble

Words With Friends uses a different board and a different point table (H is 3, L is 2, J is 10). This page is for that table. For English Scrabble values open the Scrabble word finder.

The word list is still ENABLE, not Zynga’s private list, so a few plays may bounce in the official app.
